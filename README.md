# Kids-Games · 亲子小游戏合集

为本家两位小朋友打造的小游戏合集，目标是用**轻量、好玩、安全、可离线**的小游戏，
让两个孩子在屏幕时间里有所得、有所乐。

## 👧👦 两位玩家

| 孩子 | 年龄 | 特点 | 游戏方向 |
|------|------|------|----------|
| 大宝 | 12 岁 | 能读较长文字、可独立操作、喜欢有目标的挑战 | 解谜 / 策略 / 轻度竞技 / 关卡进阶 |
| 小宝 | 7 岁 | 识字量有限、以直观操作为主 | 认知启蒙 / 手眼协调 / 色彩与形状 / 简单拖拽 |

> 适龄是第一条原则：同一个主题可以做成两个难度版本，分别放进对应目录。

## 🎯 设计原则

- **适龄**：12 岁偏策略与目标感，7 岁偏直观与即时反馈。
- **安全**：无第三方追踪、无内购、无外部跳转链接，家长可放心。
- **轻量**：优先网页（HTML/CSS/JS），浏览器打开即玩，可离线运行。
- **共创**：以孩子的真实反馈驱动迭代——觉得不好玩就改。

## 🛠 技术路线（建议）

- 纯前端：HTML5 + CSS + 原生 JavaScript（或小巧的游戏框架）。
- 无需安装、无需服务器，双击 `index.html` 即可运行。
- 仓库通过 **Git + SSH** 同步到 GitHub，电脑端与手机端可接力开发。

## 📁 目录规划（待填充）

```
games/

  7plus/     # 面向 7 岁的游戏
```

## 🚀 如何运行

直接用浏览器打开对应游戏的 `index.html` 即可，无需任何构建步骤。

## 🔄 同步方式

本仓库 remote 为 `git@github.com:sean-zhangxin/Kids-Games.git`。
本地提交后执行 `git push` 即可同步到 GitHub，跨设备 `git pull` 继续开发。

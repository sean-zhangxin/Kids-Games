# Kids-Games · 亲子妖怪 RPG

为家里两位小朋友（大宝 12 岁 / 小宝 7 岁）打造的**奇幻妖怪收集 RPG**：
用课程题当妖怪的「招式」去打怪——答对=出招命中、答错=己方挨打，
打赢攒经验升级，攒够条件看妖怪**进化变形变强**。学习被直接体验为
「让自己的妖怪变厉害」的战斗力量。

## 👧👦 两位玩家

| 孩子 | 年龄 / 年级 | 特点 | 游戏方向 |
|------|------|------|----------|
| 大宝 | 12 岁 / 初一 | 能读较长文字、独立操作、喜欢目标感与挑战 | 妖怪 RPG（收服/升级/进化），题目走初一语数英 |
| 小宝 | 7 岁 / 1–2 年级 | 识字量有限、以直观操作为主 | 妖怪 RPG（同壳），题目走 1–2 年级语数英 |

> **双轨分流（身份即题库路由）**：题目由**登录身份**决定——大宝登录抽初一题、小宝（二宝）登录抽 1–2 年级题，单一路由键、无手动切换。
> 同一只妖怪、同一段动画，大宝答初一题、小宝答 1–2 年级题——"玩法一样，题目不同"。
> 进度各自计算、资源各自池（共玩模型 A：各自设备、各自进度、同主题世界）。

## 🎮 当前主线游戏：奇幻妖怪 RPG

- **核心循环**：收服妖怪 → 用科目题打怪升级 → 帮妖怪进化（形态+数值变化是孩子最爱的部分）
- **学习即战力**：课程题 = 妖怪的「招式」；答对命中、答错己方挨打
- **战斗属性 = 科目（三系 RPS）**：

  | 攻击 \ 防守 | 语文 | 数学 | 英语 |
  |---|---|---|---|
  | **语文** | ×1.0 | ×0.67 | **×1.5** |
  | **数学** | **×1.5** | ×1.0 | ×0.67 |
  | **英语** | ×0.67 | **×1.5** | ×1.0 |

  克制环 = **语文 > 英语 > 数学 > 语文**。两孩共用同一张表。
- **等级（LV）纪律**：LV 只涨 HP/ATK 基线，**不碰克制倍率**——选对属性永远比单纯练级更值，防年长练级碾压年幼。
- **进化双门槛**：妖怪进化需**同时满足** ① 等级达标（LV ≥ T_LV）② 通过「本属性科目综合考试」（按登录身份年级抽题、正确率达标）。学习是进化的硬前置，无法靠纯刷怪绕过。
- **题型限制各异**：选择题统一倒计时（超时=miss=己方挨打）、填空限尝试次数等，不同题型不同节奏。
- **软惩罚**：妖怪昏厥 = 撤退回基地、收藏不丢（Pokémon 式），有后果但不残忍。
- **范围决策**：建造/家园元层**已砍**，当前聚焦妖怪 RPG 主线。

## 🎯 设计原则

- **适龄**：大宝偏策略与目标感，小宝偏直观与即时反馈；同一主题靠题目难度分流而非另做一版。
- **安全**：无第三方追踪、无内购、无外部跳转链接，家长可放心。
- **轻量（运行成本低，而非"必须是网页"）**：体积小、即开即玩、可离线。交付可以是网页离线包或轻量安装包——技术选型开放。
- **离线优先**：不依赖网络，所有素材本地打包，不用 CDN。
- **数据驱动 / 孩子可改**：妖怪、题库、克制表抽到 JSON 配置里，让 12 岁孩子**参与设计**（调数值、换素材、加题目）而不碰代码；理想情况下提供简易「设计模式」。
- **共创**：以孩子的真实反馈驱动迭代——觉得不好玩就改。

## 🛠 技术路线

- **开发引擎：Godot**（开源、体积小、GDScript 易读；适合家长开发，也适合 12 岁在可视化编辑器里参与设计）。
- **交付方式：HTML5 导出为主**——导出后在华为浏览器（手机/平板）里离线打开即玩，零安装；因设备为 Android 系，也可额外导出 **Android APK** 安装。
- **工程文件是文本**（`.tscn` 场景、`.gd` 脚本、资源文件），天然适合 Git + SSH 同步到 GitHub，跨设备接力开发。
- 不强制「纯前端」：引擎开发同样满足轻量与离线。

## 🚀 如何运行

- **玩家**：打开导出的 HTML5 包（离线即玩），或在华为设备上安装 APK。
- **开发**：用 Godot 打开工程，编辑场景/脚本/数据；改动后导出交付。

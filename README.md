# Kids-Games · 亲子小游戏合集

为本家两位小朋友打造的小游戏合集，目标是用**轻量、好玩、安全、可离线**的小游戏，
让两个孩子在屏幕时间里有所得、有所乐。

## 👧👦 两位玩家

| 孩子 | 年龄 | 特点 | 游戏方向 |
|------|------|------|----------|
| 大宝 | 12 岁 | 能读较长文字、可独立操作、喜欢有目标的挑战 | 解谜 / 策略 / 轻度竞技 / 关卡进阶 |
| 小宝 | 7 岁 | 识字量有限、以直观操作为主 | 认知启蒙 / 手眼协调 / 色彩与形状 / 简单拖拽 |

> 适龄是第一条原则：同一个主题可以做成两个难度版本，分别放进对应目录。

## 🎯 设计原则

- **适龄**：12 岁偏策略与目标感，7 岁偏直观与即时反馈；同一主题可做两个难度版本。
- **安全**：无第三方追踪、无内购、无外部跳转链接，家长可放心。
- **轻量（运行成本低，而非"必须是网页"）**：体积小、即开即玩、能在普通硬件甚至离线运行。交付形式可以是网页离线包，也可以是轻量安装包——技术选型开放。
- **离线优先**：不依赖网络，所有素材本地打包，不用 CDN。
- **数据驱动 / 孩子可改**：游戏内容（词库、关卡、颜色、难度）抽到简单配置或引擎资源里，让 12 岁孩子**参与设计**（调数值、摆关卡、换素材）而不碰代码；理想情况下提供一个简易"设计模式"。
- **共创**：以孩子的真实反馈驱动迭代——觉得不好玩就改。

## 🛠 技术路线

- **开发引擎：Godot**（开源、体积小、GDScript 易读；适合家长开发，也适合 12 岁在可视化编辑器里参与设计）。
- **交付方式：HTML5 导出为主**——导出后在华为浏览器（手机/平板）里离线打开即玩，零安装；因设备为 Android 系，也可额外导出 **Android APK** 安装。
- **工程文件是文本**（`.tscn` 场景、`.gd` 脚本、资源文件），天然适合 Git + SSH 同步到 GitHub，跨设备接力开发。
- 不强制"纯前端"：引擎开发同样满足轻量与离线。

## 📁 目录规划（待填充）

```
games/
  12plus/    # 面向 12 岁的游戏（Godot 工程或子场景）
  7plus/     # 面向 7 岁的游戏
  shared/    # 共用素材、工具函数、通用组件
```

> Godot 工程文件与导出产物按 `.gitignore` 规则管理：**源码入库，构建产物忽略**。

## 🚀 如何运行

- **玩家**：打开导出的 HTML5 包（离线即玩），或在华为设备上安装 APK。
- **开发**：用 Godot 打开工程，编辑场景/脚本；改动后导出交付。

## 🔄 同步方式

本仓库 remote 为 `git@github.com:sean-zhangxin/Kids-Games.git`。
本地提交后 `git push` 同步到 GitHub，跨设备 `git pull` 继续开发。

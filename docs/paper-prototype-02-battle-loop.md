# 纸上原型 02：战斗 + 收服 + 进化 循环

> **版本**：v0.1 · 2026-08-09 · 纸面走查，未写代码
> **状态**：**取代 paper-prototype-01（温和捕获切片）**。修正来源：用户反馈——两孩常玩 Minecraft/Pokémon，本就接受失败惩罚；孩子明确偏好「收服妖怪 → 打怪升级 → 帮妖怪进化」，进化后的形态/数值变化是他们最爱的部分。故设计回正为"正宗妖怪收集 RPG + 学习即战力"。
> **范围**：走「遭遇野生妖怪 → 答题打怪 → 削弱后收服 → 攒 XP 升级 → 推演进化」这一竖切。建造（Minecraft 半边）降为「妖怪家园」元层，不在本原型主走查。
> **假设**：7岁 ≈ 小学 1–2 年级（按年龄反推，待家长确认实际就读年级）。

---

## 1. 修订 Fun Hypothesis

**这游戏好玩的核心是**——用课程挑战当妖怪的「招式」去打怪：答对=出招命中、答错=挨打，打赢攒经验升级，攒够进化看妖怪变形变强。孩子把学习体验成「让自己的妖怪变厉害、打赢、进化」的战斗力量。

## 2. 修订 Design Pillars

| # | 支柱 | 说明 |
|---|---|---|
| 1 | 同一世界、共同冒险（各自进度） | 两孩玩同一套机制、同一主题世界，进度各算、资源各池 |
| 2 | 收服 → 战斗 → 升级 → 进化 主循环 | 正宗妖怪收集 RPG，不是温和捕获 |
| 3 | 学习即战力 | 课程挑战 = 出招；答对命中、答错挨打 |
| 4 | 内容双轨分流 | 同壳战斗机制，按年龄/学科自动换题 |
| 5 | 进化是可见大奖 | 形态 + 数值变化，孩子最爱的部分，核心留存钩子 |

> 已删除 pp-01 的「零挫败捕获」支柱。改为「**有公平风险的战斗**」：妖怪昏厥 = 撤退、无永久损失（Pokémon 式软惩罚）。

---

## 3. 核心循环（战斗向）

- **Moment-to-Moment（每回合几秒~几十秒）**：遭遇妖怪 → 每回合弹出一道按孩子分流的题 → 答对=己方妖怪造成 X 伤害、答错=己方妖怪挨 X 伤害 → 野生妖怪 HP 归零触发收服窗口
- **Session（开放式，不限时长）**：打完几只野怪（+ 可选训练师战）→ 攒够 XP 升 1–2 级 → 回基地用材料/进化石；收服进度 + 图鉴
- **Long-term（hours–weeks）**：图鉴收集 + 进化树（形态变化）+ 妖怪家园建造（元层）+ 每日新妖怪（留存钩子）

---

## 4. 失败 / 惩罚模型（用户要求"有惩罚"）

| 事件 | 后果 | 性质 |
|---|---|---|
| 己方妖怪 HP 归零（昏厥） | 战斗失败、撤退到基地；本次无 XP / 未收服；**收藏不丢** | 软惩罚（Pokémon 式） |
| 收服失败（挣脱） | 野生妖怪回少量血，可再战/再捕，多耗 1 回合 | 软惩罚、可重试 |
| 训练师战胜玩家 | 玩家「回基地」，无永久损失 | 软惩罚 |

**难度按年龄调**（公平非劝退）：7岁打弱怪（低 HP）+ 低年级题；12岁打强怪（高 HP、多招式）+ 高年级题。失败有后果，但不残忍。

## 7. 竖切走查：小宝（7岁）打一只野生妖怪并收服

| 步 | 玩家动作 | 系统反馈（视觉 / 音频 / 触觉） | 状态 |
|---|---|---|---|
| 1 | 小宝在字灵森林走到野生「墨点点」旁 | 遭遇！双方妖怪登场（火灵狐 vs 墨点点），BGM 起 | 进入战斗 |
| 2 | 回合1：题卡「火 的拼音？」（语文·识字·1年级） | 火灵狐蓄力光圈 | 出题 |
| 3 | 小宝点 huǒ（对） | ✅ 火灵狐扑击 + 命中音 + 伤害数字「-12」弹出 | 墨点点 HP 30→18 |
| 4 | 回合2：题「圈出 火」 | 选项大按钮带图 | 出题 |
| 5 | 小宝圈对 | ✅ 火灵狐喷小火 + 墨点点缩一下 | 墨点点 HP 18→6 |
| 6 | 墨点点 HP ≤ 30% | 屏幕弹「收服！」按钮闪金光 | 进入收服窗口 |
| 7 | 收服题「火 的笔画数？」（稍难） | 捕获球旋转动画 | 出题 |
| 8 | 小宝答对 | ✅ 球命中、墨点点入队 + 掉落材料 + 图鉴 +1 音效 | 收服成功，材料 +2 |
| 9 | （分支）若答错 | 墨点点挣脱、回血到 12，提示「再试一次」 | 可再战/再捕（多耗回合） |
| 10 | （失败分支）若小宝连错致火灵狐 HP 0 | 火灵狐倒下 + 低沉音 → 撤退回基地 | 本次无收获（软惩罚） |

→ 单场约 2–4 分钟；胜则推进图鉴与 XP，败则软惩罚重来。

## 9. 这条循环「坏掉长什么样」（playtest 失败信号）

| 信号 | 现象 | 含义 |
|---|---|---|
| A | 孩子觉得战斗像考试，不兴奋 | 学习没融进爽感，融合不够，需让出题更「招式化」 |
| B | 7岁因频繁昏厥而挫败弃玩 | 软惩罚变太硬，难度 / HP 需调参 |
| C | 几周都触发不了进化 | 阈值 / XP 曲线错 |
| D | 收服纯看运气、无成就 | 捕获题难度 / 反馈需调 |

**成功定义**：孩子连打多场、主动刷怪，并出现「我的 XX 进化了！」式欢呼。

## 10. 结论

- Fun Hypothesis 在战斗切片里**逻辑自洽**：答题=出招、打赢=升级、攒够=进化，学习全程驱动 RPG 主循环。
- 最大风险在 **A（融合不够显生硬）** 与 **B（软惩罚对低龄偏硬）**——真机重点看。
- 下一步：纸面通过后进 Godot 搭 **P1 MVP**（1 妖怪 + 战斗 + 收服 + 进化，语文·识字；12岁切片做数学·分数换轨）。
- Minecraft 建造半边以「妖怪家园」元层实现，是否保留待用户确认。

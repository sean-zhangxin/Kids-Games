# 纸上原型 02：妖怪 RPG 战斗 + 收服 + 进化 循环

> **版本**：v0.3 · 2026-08-09 · 纸面走查，未写代码
> **相对 v0.2 的变更（本次）**：
> 1. **身份即题库路由**：登录身份（大宝/小宝）成为年级与题库的**唯一路由键**——出什么题完全由"谁登录"决定。
> 2. **进化改双门槛**：进化需**同时满足** ① 等级达标（LV ≥ T_LV）② 通过「本属性科目综合考试」（按登陆身份年级抽题）。学习成为进化的硬前置。
> 3. **题型→限制映射**：不同题型不同规矩（选择题统一倒计时、填空限尝试次数等），超时/失败统一结算为"miss=己方挨打"。

---

## 1. Fun Hypothesis

**这游戏好玩的核心是**——用课程题当妖怪的「招式」去打怪：答对=出招命中、答错=己方挨打，打赢攒经验升级，攒够**等级 + 学科考试**双门槛看妖怪进化变形变强。孩子把学习体验成「让自己的妖怪变厉害、打赢、进化」的战斗力量。

## 2. Design Pillars

| # | 支柱 | 说明 |
|---|---|---|
| 1 | 同一世界、共同冒险（各自进度） | 两孩玩同一套机制、同一主题世界，进度各算、资源各池 |
| 2 | 收服 → 战斗 → 升级 → 进化（双门槛）主循环 | 正宗妖怪收集 RPG；进化需等级 AND 考试 |
| 3 | 学习即战力 | 课程题 = 出招；答对命中、答错己方挨打 |
| 4 | 身份即题库路由 | 登录身份决定年级与题库，单一路由键，无手动切换 |
| 5 | 进化是可见大奖 | 形态 + 数值变化，孩子最爱的部分，核心留存钩子 |

## 3. 核心循环

- **Moment-to-Moment（每回合几秒~几十秒）**：遭遇妖怪 → 每回合弹出一道**按登录身份分流**的科目题 → 答对=己方妖怪造成 伤害、答错=己方妖怪挨 伤害（敌方也按克制关系出招）→ 一方 HP 归零结束回合
- **Session（开放式，不限时长）**：打完几只野怪 → 攒够 XP 升 1–2 级 → 收服进度 + 图鉴 +1
- **Long-term（hours–weeks）**：图鉴收集 + 进化树（形态变化）+ 每日新妖怪刷新（留存钩子）

## 4. 战斗属性克制（语数英 三系）

| 攻击方 \ 防守方 | 语文 | 数学 | 英语 |
|---|---|---|---|
| **语文** | ×1.0 | ×0.67 | **×1.5** |
| **数学** | **×1.5** | ×1.0 | ×0.67 |
| **英语** | ×0.67 | **×1.5** | ×1.0 |

克制环 = **语文 > 英语 > 数学 > 语文**（语文克英语、英语克数学、数学克语文）。

**伤害公式**：

```
伤害 = 基础ATK(等级) × 克制倍率 × 命中系数
命中系数：答对 = 1.0，答错 = 0（本回合未造成伤害、己方挨一下）
```

**等级（LV）纪律**：LV 只决定 `基础ATK` 与 `最大HP` 的基线斜率；**克制倍率恒为 ×1.5 / ×0.67 / ×1.0，不受 LV 影响**。这样大宝 LV50 也吃不满对小宝 LV5 的克制亏，选对属性永远比堆级更值。

## 5. 失败 / 惩罚模型（用户要求"有惩罚"）

| 事件 | 后果 | 性质 |
|---|---|---|
| 己方妖怪 HP 归零（昏厥） | 战斗失败、撤退回基地；本次无 XP / 未收服；**收藏不丢** | 软惩罚（Pokémon 式） |
| 收服失败（挣脱） | 野生妖怪回少量血，可再战/再捕，多耗 1 回合 | 软惩罚、可重试 |
| 训练师战胜玩家 | 玩家「回基地」，无永久损失 | 软惩罚 |
| 答题超时 / 超限（见 §8） | 该回合 = miss（己方挨打、本回合 0 伤害） | 软惩罚，复用同一结算 |

**难度按年龄调**（公平非劝退）：小宝打弱怪（低 HP）+ 1–2 年级题；大宝打强怪（高 HP、多招式）+ 初一题。失败有后果，但不残忍。

## 6. 收服机制

- 野生妖怪 HP 削弱到阈值（例 ≤30% `[PLACEHOLDER]`）后弹出「收服！」窗口
- 收服动作 = 答一道稍难的该科目题；答对=入队，答错=挣脱可再捕
- 收服后入队，可继续升级 / 进化

## 7. 进化（双门槛：等级 AND 学科综合考试）

进化是孩子最爱的留存钩子，也是「学习变强」最强正反馈。采用**双门槛**，两者必须**同时满足**：

| 门槛 | 条件 | 含义 |
|---|---|---|
| 等级门槛 | 妖怪 LV ≥ T_LV `[PLACEHOLDER]` | 传统练级积累 |
| 学科综合考试 | 在**本妖怪属性科目**上通过综合考：抽 N 题 @ 本账号年级（覆盖 ≥3 知识点），正确率 ≥ X% `[PLACEHOLDER]` | 以学代练，必过项 |

- **综合考试流程**：妖怪 LV 达标后，玩家在该妖怪界面发起「进化考试」→ 系统从**本妖怪属性科目**、按**登录身份对应的年级池**抽 N 题（同样受 §8「题型→限制」约束，选择题限时）→ 正确率达标即进化；不达标可重考（软惩罚、无损失）。
- **为何双门槛**：等级保证战斗投入，考试保证学科掌握；二者结合让"学习"成为进化的硬前置，无法靠纯刷怪绕过。更硬核更慢，但契合「课程学习结合游戏」初衷。
- **演出**：变形动画 + 新形态（更大 / 换色 / 换部件）+ 数值提升（HP / ATK）+ 解锁新「招式类型」（新题类）。

## 8. 题型 → 答题限制映射

不同题型给不同限制，制造节奏差异；**超时/超限统一结算为 miss（己方挨打、本回合 0 伤害）**，复用 §5 的软惩罚，不新增失败类型。

| 题型 | 限制 | 超时/失败结算 | 数值 `[PLACEHOLDER]` |
|---|---|---|---|
| 选择题 | **统一倒计时** | 视为 miss | 时限 10s（**统一，不按年级缩放**） |
| 填空题 | 无时限、尝试 ≤ K 次 | 用完 = miss | K=3 |
| 连线 / 拖拽 | 无时限 | 错连可重连 | — |
| 跟读 / 听音（英） | 录制 ≤ M 次 | 超次 = miss | M=2 |

> **统一时限的设计判断**：题库已按登录身份分池（初一 vs 1–2 年级），难度天然适龄，故不再叠加年级缩放。但需 playtest 信号 F 盯小宝是否因计时焦虑而乱点（见 §11）。综合考试同样适用本表，且整体可更紧。

## 9. 身份即题库路由（单一路由键）

| 登录身份 | 年级 | 战斗属性（=科目） | 题库来源 |
|---|---|---|---|
| 大宝 | 初一 | 语文 / 数学 / 英语 | 初一语数英池 |
| 小宝（二宝） | 1–2 年级 | 语文 / 数学 / 英语 | 1–2 年级语数英池 |

- **路由规则**：`登录身份 → 年级 → 题库`。出什么题**完全由谁登录决定**，战斗中不做手动年级切换。
- 两孩共用同一张克制表（语数英三系）；同一只妖怪、同一动画，**背后是两套年级题**——"玩法一样、题目不同"。
- 该身份同时决定 §7 综合考试的抽题年级与 §8 的题型限制适用性。

## 10. 经济草图（各孩子独立池，避免年长碾压）

| 资源 | Source | Sink |
|---|---|---|
| 经验 XP | 战斗胜利 | 升级 / 进化（等级门槛） |
| 知识结晶 | 答对题（按难度给） | 进化、解锁新招式 |
| 捕获球 | 每日登录少量 / 结晶兑换 | 收服消耗 |
| 伤药 | 结晶兑换 / 探索 | 回血 |

## 11. 竖切走查

### 11.1 小宝（1–2 年级）打「墨点点」（数学系）

| 步 | 玩家动作 | 系统反馈 | 状态 |
|---|---|---|---|
| 1 | 走到野生「墨点点」（数学系）旁 | 遭遇！火灵狐（语文系）vs 墨点点，BGM 起 | 进入战斗 |
| 2 | 回合1：题「3 + 5 = ?」（数学·1年级·选择题，10s 倒计时） | 火灵狐蓄力光圈 + 倒计时环 | 出题 |
| 3 | 小宝点 8（对） | ✅ 扑击 + 命中音 + 「-12」 | 墨点点 HP 30→18 |
| 4 | 墨点点反击（数学系 vs 语文系 = 被克 ×0.67） | 小伤数字「-4」 | 火灵狐 HP 100→96 |
| 5 | 回合2~N 持续答对 | 墨点点 HP 递减 | 墨点点 HP 18→0 |
| 6 | 墨点点 HP 0 | 「收服！」金光按钮 | 收服窗口 |
| 7 | 收服题「7 - 2 = ?」（稍难·填空，限 3 次） | 捕获球旋转 | 出题 |
| 8 | 小宝答对 | ✅ 入队 + 结晶 +1 + 图鉴 +1 | 收服成功 |

→ 单场约 2–4 分钟。火灵狐(语文) 打 墨点点(数学) 时**数学克语文**，演示"属性不对会吃亏"，但小宝靠答对率高仍能赢（命中系数主导）。真机重点看信号 B（是否感知被克）、F（选择题计时焦虑）。

### 11.2 大宝（初一）打「潮汐兽」（英语系）

| 步 | 玩家动作 | 系统反馈 | 状态 |
|---|---|---|---|
| 1 | 走到野生「潮汐兽」（英语系）旁 | 雷鸣兽（数学系）vs 潮汐兽 | 进入战斗 |
| 2 | 回合1：题「Choose the past tense of 'go'」（初一·英·选择题，10s） | 雷鸣兽蓄电 + 倒计时环 | 出题 |
| 3 | 大宝点 went（对） | ✅ 放电 + 「-15」；数学克英语 → ×1.5 → 实际 -22 | 潮汐兽 HP 60→38 |
| 4 | 潮汐兽反击（英语 vs 数学 = 被克 ×0.67） | 小伤「-5」 | 雷鸣兽 HP 120→115 |
| 5 | 持续答对 | 潮汐兽 HP→0 | 收服窗口 |
| 6 | 收服题（较难初中英语·填空）答对 | ✅ 入队 + 结晶 + 图鉴 | 收服成功 |

→ 同壳换轨验证：机制完全一样，只题变难、妖怪数值更高、计时同 10s。**克制倍率对两孩一致**，大宝不会因题难自动碾压小宝的属性博弈。

### 11.3 进化双门槛走查（以小宝的语文妖怪「火灵狐」为例）

| 步 | 条件 | 系统反馈 |
|---|---|---|
| 1 | 火灵狐 LV 达 T_LV（练级达成） | 妖怪界面亮起「可进化考试」 |
| 2 | 小宝发起「进化考试」 | 从**语文·1–2 年级**池抽 N 题（≥3 知识点，选择题含 10s 倒计时） |
| 3 | 正确率 ≥ X% | ✅ 变形动画 + 新形态 + HP/ATK 提升 + 解锁新招式 |
| 4 | 未达标 | 软提示「再复习一下」，可重考，无损失 |

→ 等级（战斗投入）与考试（学科掌握）双满足才进化；考试抽的是本妖怪属性科目 + 本登录身份年级，强化"学对应科目=养对应妖怪"。

## 12. 系统交互矩阵（提前暴露风险）

| 系统对 | 关系 | 备注 |
|---|---|---|
| 登录身份 × 题库 | **intended** | 登陆即定年级，单一路由键 |
| 妖怪属性 × 考试科目 | **intended** | 考本妖怪的科目 |
| 选择题计时 × 软惩罚 | **intended** | 超时 = miss = 己方挨打 |
| 综合考 × 战斗循环 | **acceptable 但需监控** | 考试为必过门槛，靠难度档 + 限时压住，不架空战斗 |
| 双门槛 × 进度节奏 | **risk** | 进化更慢，需信号 D/F 监控是否卡墙 |

## 13. 这条循环「坏掉长什么样」（playtest 失败信号）

| 信号 | 现象 | 含义 |
|---|---|---|
| A | 孩子觉得战斗像考试，不兴奋 | 学习没融进爽感，需让出题更「招式化」 |
| B | 孩子不知道自己被克（无克制反馈） | 克制系统没做出来/没演出，需加属性提示 |
| C | 练级碾压克制（高 LV 无视倍率） | 倍率失衡，需复查 LV 不碰倍率的纪律 |
| D | 几周触发不了进化 / 双门槛卡墙 | 阈值或考试太难，需放宽 T_LV / X% |
| E | 答错题与扣血因果脱节（乱点不看题） | 反馈通道断了，需强化"答错=挨打"的视听 |
| F | 小宝在选择题上因统一计时焦虑、乱点 | 即便题库适龄，10s 仍可能压低龄；需下调时限或给低年级放宽 |

**成功定义**：孩子连打多场、主动刷怪，并出现「我的 XX 进化了！」式欢呼；且能说出"我用语文打英语赚到了"；并能主动回基地发起进化考试。

## 14. 结论

- Fun Hypothesis 在战斗切片里**逻辑自洽**：答题=出招、打赢=升级、双门槛=进化，学习全程驱动 RPG 主循环。
- 三系 RPS + LV 不碰倍率，已规避"年长练级碾压年幼"；**身份路由 + 双门槛**进一步把"学习"焊成进化硬前置。
- 最大风险在 **A（融合生硬）**、**B（克制无感）**、**E（因果脱节）**、**F（计时焦虑）**——真机重点看。
- 下一步：纸面通过后进 Godot 搭 **P1 MVP**（1 妖怪 + 战斗 + 收服 + 进化双门槛，语文；双孩身份路由 + 题型限制）。

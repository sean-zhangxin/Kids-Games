纸上原型 02 v0.2：妖怪 RPG 战斗 + 收服 + 进化 循环

纸面走查 2026-08-09 · 未写代码

相对 v0.1 的变更（本次对齐）：
1. 砍掉建造元层——聚焦妖怪 RPG 主线。
2. 双孩年级确认：小宝 = 1–2 年级；大宝 = 初一。
3. 战斗属性 = 科目：语/数/英 三系直接当属性，克制环 语文 > 英语 > 数学 > 语文，两孩共用。
4. 等级（LV）只涨 HP/ATK，不碰克制倍率——防年长练级碾压年幼。
5. 不纠结克制逻辑合理性——孩子只图爽，三系 RPS 是纯乐趣机制。

1. Fun Hypothesis

这游戏好玩的核心是——用课程题当妖怪的「招式」去打怪：答对=出招命中、答错=己方挨打，打赢攒经验升级，攒够条件看妖怪进化变形变强。

2. Design Pillars

#支柱说明
1同一世界、共同冒险（各自进度）两孩玩同一套机制、同一主题世界，进度各算、资源各池
2收服 → 战斗 → 升级 → 进化 主循环正宗妖怪收集 RPG
3学习即战力课程题 = 出招；答对命中、答错己方挨打
4内容双轨分流同壳战斗机制，按年龄/年级自动换题
5进化是可见大奖形态 + 数值变化，孩子最爱的部分，核心留存钩子

3. 核心循环

  • Moment-to-Moment（每回合几秒~几十秒）：遭遇妖怪 → 每回合弹出一道按孩子分流的科目题 → 答对=己方造成 伤害、答错=己方挨 伤害（敌方也按克制关系出招）→ 一方 HP 归零结束回合
  • Session（开放式，不限时长）：打完几只野怪 → 攒够 XP 升 1–2 级 → 收服进度 + 图鉴 +1
  • Long-term（hours–weeks）：图鉴收集 + 进化树（形态变化）+ 每日新妖怪刷新（留存钩子）

4. 战斗属性克制（语数英 三系）

攻击 \ 防守语文数学英语
语文×1.0×0.67×1.5
数学×1.5×1.0×0.67
英语×0.67×1.5×1.0

克制环 = 语文 > 英语 > 数学 > 语文。

伤害 = 基础ATK(等级) × 克制倍率 × 命中系数（答对=1.0 / 答错=0）

等级（LV）纪律：LV 只决定 基础ATK 与 最大HP 的基线斜率；克制倍率恒为 ×1.5 / ×0.67 / ×1.0，不受 LV 影响。大宝 LV50 也吃不满对小宝 LV5 的克制亏，选对属性永远比堆级更值。

倍率、ATK 曲线、经验曲线全部 [PLACEHOLDER]（先假设 克制 ×1.5 / 被克 ×0.67，真机校准）。

5. 失败 / 惩罚模型（用户要求"有惩罚"）

事件后果性质
己方妖怪 HP 归零（昏厥）撤退回基地；本次无 XP / 未收服；收藏不丢软惩罚（Pokémon 式）
收服失败（挣脱）野生妖怪回少量血，可再战/再捕，多耗 1 回合软惩罚、可重试
训练师战胜玩家玩家「回基地」，无永久损失软惩罚

难度按年龄调（公平非劝退）：小宝打弱怪（低 HP）+ 1–2 年级题；大宝打强怪（高 HP、多招式）+ 初一题。

6. 收服机制

  • 野生妖怪 HP 削弱到阈值（例 ≤30% [PLACEHOLDER]）后弹出「收服！」窗口
  • 收服动作 = 答一道稍难的该科目题；答对=入队，答错=挣脱可再捕
  • 收服后入队，可继续升级 / 进化

7. 进化（孩子最爱，重点设计）

  • 触发：达到等级阈值（例 Lv16 [PLACEHOLDER]）且 学科掌握度 ≥ 阈值（例 80% [PLACEHOLDER]）
  • 演出：变形动画 + 新形态（更大 / 换色 / 换部件）+ 数值提升（HP / ATK）+ 解锁新「招式类型」（新题类）
  • 意义：留存钩子核心，也是「学习变强」最强正反馈

8. 双孩题目分流

孩子年级战斗属性（=科目）题目示例（语/数/英）
小宝1–2 年级语文 / 数学 / 英语识字拼音 / 20 以内加减 / 简单单词认读
大宝初一语文 / 数学 / 英语阅读理解 / 分数·方程 / 时态·从句

两孩共用同一张克制表（语数英三系）；同一只妖怪、同一动画，背后是两套年级题——这就是"玩法一样、题目不同"。

10. 竖切走查

10.1 小宝（1–2 年级）打「墨点点」（数学系）

步玩家动作系统反馈状态
1走到野生「墨点点」（数学系）旁遭遇！火灵狐（语文系）vs 墨点点，BGM 起进入战斗
2回合1：题「3 + 5 = ?」（数学·1年级）火灵狐蓄力光圈出题
3小宝点 8（对）✅ 扑击 + 命中音 + 「-12」墨点点 HP 30→18
4墨点点反击（数学克语文 ×0.67）小伤数字「-4」火灵狐 HP 100→96
5回合2~N 持续答对墨点点 HP 递减墨点点 HP 18→0
6墨点点 HP 0「收服！」金光按钮收服窗口
7收服题「7 - 2 = ?」（稍难）捕获球旋转出题
8小宝答对✅ 入队 + 结晶 +1 + 图鉴 +1收服成功

→ 单场约 2–4 分钟。注：火灵狐(语文) 打 墨点点(数学) 时，数学克语文，火灵狐反而被克——演示"属性不对会吃亏"，但小宝靠答对率高仍能赢（命中系数主导）。真机重点看信号 B（她是否感知到自己被克）。

10.2 大宝（初一）打「潮汐兽」（英语系）

步玩家动作系统反馈状态
1走到野生「潮汐兽」（英语系）旁雷鸣兽（数学系）vs 潮汐兽进入战斗
2回合1：题「Choose the past tense of 'go'」雷鸣兽蓄电出题
3大宝点 went（对）✅ 放电 + 「-15」；数学克英语 → ×1.5 → 实际 -22潮汐兽 HP 60→38
4潮汐兽反击（英语被数学克 ×0.67）小伤「-5」雷鸣兽 HP 120→115
5持续答对潮汐兽 HP→0收服窗口
6收服题（较难初中英语）答对✅ 入队 + 结晶 + 图鉴收服成功

→ 同壳换轨验证：机制完全一样，只题变难、妖怪数值更高。克制倍率对两孩一致，大宝不会因题难自动碾压小宝的属性博弈。

11. 这条循环「坏掉长什么样」（playtest 失败信号）

信号现象含义
A孩子觉得战斗像考试，不兴奋学习没融进爽感，需让出题更「招式化」
B孩子不知道自己被克（无克制反馈）克制系统没做出来/没演出，需加属性提示
C练级碾压克制（高 LV 无视倍率）倍率失衡，需复查 LV 不碰倍率的纪律
D几周触发不了进化阈值 / XP 曲线错
E答错题与扣血因果脱节（乱点不看题）反馈通道断了，需强化"答错=挨打"的视听

成功定义：孩子连打多场、主动刷怪，并出现「我的 XX 进化了！」式欢呼；且能说出"我用语文打英语赚到了"。

12. 结论

  • Fun Hypothesis 在战斗切片里逻辑自洽：答题=出招、打赢=升级、攒够=进化，学习全程驱动 RPG 主循环。
  • 三系 RPS + LV 不碰倍率，已规避"年长练级碾压年幼"的结构性风险。
  • 最大风险在 A（融合生硬）、B（克制无感）、E（因果脱节）——真机重点看。

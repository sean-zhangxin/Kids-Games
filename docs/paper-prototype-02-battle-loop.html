1. Fun Hypothesis

这游戏好玩的核心是——用课程题当妖怪的「招式」去打怪：答对=出招命中、答错=己方挨打，打赢攒经验升级，攒够等级 + 学科考试双门槛看妖怪进化变形变强。孩子把学习体验成「让自己的妖怪变厉害、打赢、进化」的战斗力量。

2. Design Pillars

#支柱说明
1同一世界、共同冒险（各自进度）两孩玩同一套机制、同一主题世界，进度各算、资源各池
2收服→战斗→升级→进化（双门槛）主循环正宗妖怪收集 RPG；进化需等级 AND 考试
3学习即战力课程题 = 出招；答对命中、答错己方挨打
4身份即题库路由登录身份决定年级与题库，单一路由键，无手动切换
5进化是可见大奖形态 + 数值变化，孩子最爱的部分，核心留存钩子

3. 核心循环

  • Moment-to-Moment：遭遇妖怪 → 每回合弹出一道按登录身份分流的科目题 → 答对=造成伤害、答错=己方挨打 → 一方 HP 归零结束回合
  • Session（开放式）：打完几只野怪 → 攒 XP 升 1–2 级 → 收服进度 + 图鉴 +1
  • Long-term：图鉴收集 + 进化树（形态变化）+ 每日新妖怪刷新

4. 战斗属性克制（语数英 三系）

攻击\防守语文数学英语
语文×1.0×0.67×1.5
数学×1.5×1.0×0.67
英语×0.67×1.5×1.0

克制环 = 语文 > 英语 > 数学 > 语文。伤害 = 基础ATK(等级) × 克制倍率 × 命中系数；命中系数答对=1.0、答错=0。
LV 纪律：LV 只决定基础ATK/最大HP 基线；克制倍率恒 ×1.5/×0.67/×1.0，不受 LV 影响，选对属性永远比堆级更值。倍率、ATK、经验曲线全部 [PLACEHOLDER]。

5. 失败 / 惩罚模型

事件后果性质
妖怪 HP 归零（昏厥）战斗失败撤退回基地；无 XP/未收服；收藏不丢软惩罚
收服失败（挣脱）野生妖怪回少量血，可再战/再捕软惩罚、可重试
训练师战胜玩家玩家回基地，无永久损失软惩罚
答题超时 / 超限（§8）该回合 = miss（己方挨打、0 伤害）软惩罚，复用同结算

6. 收服机制

野生妖怪 HP 削弱到阈值（≤30% [PLACEHOLDER]）后弹「收服！」窗口；收服 = 答一道稍难的该科目题；答对入队、答错挣脱可再捕。

7. 进化（双门槛：等级 AND 学科综合考试）

门槛条件含义
等级门槛妖怪 LV ≥ T_LV [PLACEHOLDER]传统练级积累
学科综合考试在本妖怪属性科目上通过综合考：抽 N 题@本账号年级（覆盖≥3知识点），正确率≥X% [PLACEHOLDER]以学代练，必过项
  • 综合考试流程：LV 达标后，玩家在妖怪界面发起「进化考试」→ 系统从本妖怪属性科目、按登录身份对应年级池抽 N 题（同样受 §8 题型限制约束）→ 达标即进化；不达标可重考（软惩罚、无损失）。
  • 为何双门槛：等级保证战斗投入，考试保证学科掌握；学习成为进化的硬前置，无法靠纯刷怪绕过。更硬核更慢，但契合「课程学习结合游戏」初衷。
  • 演出：变形动画 + 新形态 + 数值提升 + 解锁新招式类型。

14. 结论

  • Fun Hypothesis 在战斗切片里逻辑自洽：答题=出招、打赢=升级、双门槛=进化，学习全程驱动 RPG。
  • 三系 RPS + LV 不碰倍率规避年长碾压；身份路由 + 双门槛把"学习"焊成进化硬前置。
  • 最大风险 A / B / E / F——真机重点看。
